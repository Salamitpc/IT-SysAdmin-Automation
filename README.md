# IT SysAdmin Automation

A practical PowerShell toolkit for Windows and Microsoft 365 administrators.

## Included
- System inventory
- Disk-space monitoring
- Network/DNS testing
- Windows update status
- Local administrators audit
- Installed software inventory
- Service health checks
- Event log error collection
- BitLocker status
- Temporary-file cleanup
- Large-file discovery

## Safety
Scripts are designed for authorized administrative use. Test in a lab before production deployment. Scripts that modify the system include safeguards where practical.

## Requirements
- Windows PowerShell 5.1 or PowerShell 7+
- Administrative privileges where noted
